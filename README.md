# Sistem Analisis PBD - SEKOLAH KEBANGSAAN KERUBONG

## Cara pasang di GitHub Pages
1. Muat naik fail `index.html` ke root repository GitHub.
2. Pergi ke Settings > Pages.
3. Tetapkan Deploy from a branch, pilih main dan /(root).
4. Tunggu GitHub Pages diterbitkan.

Versi asal biasa tanpa PWA. Nama sekolah, lencana serta lima tetapan data telah dikemas kini tanpa mengubah fungsi sistem.

**Nota:** Lencana menggunakan URL imej yang dibekalkan dan memerlukan akses internet untuk dipaparkan.
